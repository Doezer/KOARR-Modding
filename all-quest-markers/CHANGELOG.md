# Changelog

## 1.0.1

- Reworked the repository and bundled README around the working released mod.
- Added clear download, installation, upgrade, compatibility and uninstall guidance.
- Moved development commands into a separate documentation page.
- The three native patches are unchanged from 1.0.0.

## 1.0.0

- First functional native-patch release, confirmed working by the GOG/v1.4 tester.
- Shows untracked quest objectives during world-map population and target updates.
- Extends distant untracked marker rendering beyond the previous local-only result.
- Combines all three patches in `mods/all_quest_markers_native.json`.
- Ships installation documentation without diagnostic scripts or game/framework binaries.

The previous 0.1.x releases were research probes and did not implement the final
native mod. Their GitHub releases and ZIPs have been retired; source history is retained.
